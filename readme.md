# Introducción al Desarrollo Web
## Resumen del Curso
Este curso de 60 minutos introduce a estudiantes a los conceptos fundamentales de HTML y CSS para construir sitios web sencillos desde cero. **¡No requiere descargas!** Solo abre tu navegador web.

**Duración total**: ~60 minutos
**Público objetivo**: Estudiantes sin experiencia en programación
**Prerrequisitos**: Ninguno
**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)
**📂 Repositorio de código fuente**: [https://github.com/upc-pre-1ASI0730-7461-CcaritaTech/basic-web-course](https://github.com/upc-pre-1ASI0730-7461-CcaritaTech/basic-web-course)

## Secuencia de la lección

### Lección 1: ¿Qué es el Desarrollo Web? (3:52 minutos)
- **Descripción**: Aprende de qué están hechas los sitios web. Descubre qué es HTML y CSS y por qué son los pilares de la web.
- **Contenido por**: Jean Niels Arizabal Condori
- **Enlace**: [Ver la lección 1](https://www.youtube.com/watch?v=cREC2saL7ic)
- **Consejos clave**: HTML es el esqueleto (contenido), CSS es la piel (estilo).

### Lección 2: Estructura HTML Básica (7 minutos)
- **Descripción**: Aprende la estructura fundamental de un documento HTML, incluyendo etiquetas, elementos y atributos.
- **Contenido por**: Brayan Roberto Ccarita Cruz
- **Enlace**: [Ver la lección 2](https://www.youtube.com/watch?v=fOGtoDqKvxo)
- **Consejos clave**: `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`.
- **Práctica**: [Crea tu primer estructura HTML](https://codepen.io/pen/?template=WNbjWJp)

### Lección 3: Elementos HTML Comunes (10:48 y 8:28 minutos)
- **Descripción**: Agrega contenido real a tu página. Aprende a usar encabezados, párrafos, listas, imágenes y enlaces.
- **Contenido por**: Brayan Roberto Ccarita Cruz
- **Enlace 1**: [Ver la lección 3 pt.1](https://www.youtube.com/watch?v=1RClQ7Udio0)
- **Enlace 2**: [Ver la lección 3 pt.2](https://www.youtube.com/watch?v=WYez4NB4BZY)
- **Consejos clave**: `<h1>` a `<h6>`, `<p>`, `<ul>`, `<ol>`, `<li>`, `<img>`, `<a>`.
- **Práctica**: [Añade contenido a tu página](https://codepen.io/pen/?template=WNbjWJp)

### Lección 4: Aprendiendo CSS Básico con Juegos (14:16 minutos)
- **Descripción**: ¡Aprende CSS de la forma divertida! Practica selectores, propiedades y valores de CSS a través de desafíos y juegos interactivos.
- **Contenido por**: Axel Randall Ordoñez Ricaldi	
- **Enlace**: [Ver la lección 4](https://www.youtube.com/watch?v=Kzd6j03gp0Y)
- **Consejos clave**: `selector { propiedad: valor; }`.
- **Práctica**: [Juega CSS Diner](https://flukeout.github.io/) 👈 **¡Practica selectores!**

### Lección 5: Creación de una Página Web Básica (15:26 minutos)
- **Descripción**: Es hora de construir. Combina tus conocimientos de HTML y CSS para estructurar y dar estilo a una página de perfil personal.
- **Contenido por**: Yeira Shari Huaman Olivos y Fabrizio Martin Panta Castro
- **Enlace**: [Ver la lección 5](https://www.youtube.com/watch?v=16r98UYYPz8)
- **Consejos clave**: Conecta tu archivo `.css` a tu `.html` usando la etiqueta `<link>`.
- **Proyecto**: [Inicia tu proyecto en CodePen](https://codepen.io/pen/?template=WNbjWJp) 👈 **¡No necesitas registrarte!**

### Lección 6: Errores Comunes y Buenas Prácticas (7:38 minutos)
- **Descripción**: Mejora tu código. Aprende a evitar los errores más comunes de HTML y CSS y aplica buenas prácticas para que tu código sea limpio y profesional.
- **Contenido por**: Jean Niels Arizabal Condori
- **Enlace**: [Ver Lección 6](https://www.youtube.com/watch?v=nCdAB55qh_I)
- **Consejos Clave**: ¡No olvides cerrar tus etiquetas! Usa nombres de clases descriptivos.
 - **Práctica**: [Refactoriza tu código](https://replit.com/new/html)
